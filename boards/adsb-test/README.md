# ADSB_Test

ESP32-P4 based ADS-B test board, derived from the Waveshare
ESP32-P4-WIFI6-Touch-LCD-7B-C reference board. It is kept as close to the
reference board as possible, so firmware and circuits can be proven on the
reference board while ADSB_Test is designed.

**Hardware revision:** Rev A (design started 2026-10-09). **Status:** requirements / architecture draft.

## Features

- **OSPTEK ESP32-P4C5 Core** module: ESP32-P4 (rev v3) + ESP32-C5 (dual-band Wi-Fi 6 backup link over SDIO, esp_hosted, same wiring as the reference board's C6), 16 MB flash, 32 MB PSRAM, IPEX antenna; 1.0 mm stamp holes
- P4 RTC on the always-on backup supply (optional DS3231M, not fitted by default)
- **ADSBee m1421** dual-band ADS-B receiver (1090 MHz Mode S + 978 MHz UAT), RF front end copied from the ADSBee 1421 carrier
- 10/100 Ethernet (LAN8720A RMII PHY, HR911105A RJ45 MagJack)
- **User USB-C:** USB-PD sink (main power + charging) and a USB-UART to the P4 user UART
- **Dev USB-C:** one cable for all debug: P4 USB-Serial/JTAG, P4 + C5 UARTs with auto-reset (FT2232H), m1421 console + firmware upload (RP2040 with ADSBee 1421 Programmer firmware). m1421 JTAG on a J-Link header
- **USB-A host** (P4 USB 2.0 HS) to an external hub: 1 SDR (AIS etc.), 2 supported, 4 nice-to-have
- GNSS module with PPS
- ≈ 188 × 97 mm board (screen + 12 mm margins on the short edges) with the 7" EK79007 panel bonded to its top side (Waveshare stack-up, all parts on the bottom). 3D-printed plastic case, thicker long walls Digital connectors on one edge; GNSS and ADS-B SMA connectors on the opposite edge, with optional RF cans
- 2S1P 18650 Li-ion (≥ 1 h with everything running), buck-boost charger with power path
- Voltage + current monitoring on every rail (3 × PAC1954, 12 channels)
- Same 7" 1024×600 MIPI-DSI display and touch as the reference board
- microSD (kept from the reference board). Audio, CAN, RS485 and camera dropped
- Test points on every rail, and a 2×20 keyed header for the **Kingst LA5016** cable: 16 key digital signals + PWM outputs. Second row reserved for an LA5032
